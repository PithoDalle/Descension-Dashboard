Drop race portrait images here, named <race>_<gender>.png (or .jpg/.jpeg/.webp), e.g.:
  human_male.png
  human_female.png
  orc_male.png
  ...
Race names: human, orc, dwarf, nightelf, undead, tauren, gnome, troll, bloodelf, draenei.
Gender: male or female.

The Armory tab looks for these automatically -- nothing else needs to change. A race with
no matching file just shows "No portrait for this race yet" instead of an image.
