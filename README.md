# Descension Dashboard
This tool is a dashboard for server admins. It comes with a way to start, stop and restart MySQL, Authserver and Worldserver, it also includes  SquidBots Dashboard, a Live map where you can TP where you right click, Show WF and bot/player locations. It has built in Sidekick and you can attach DB.Exile as well. You can controll accounts, add items + add items to favorite for easy access and even make kits. You can see and control bans/mutes, tickets and alter realmlist data, and lastly it includes a built in lua script editor with a list of all your configs.

Full Feature list:
- Dashboard to start/stop MySQL, Authserver, Worldserver + Worldserver Realm2 if you have 2 realms.
- Consoles for each of the above.
- Playerbots-Dashboard by Squid implemented but altered to fit my dashboard.
- Armory with a feature to give items to players and bots directly from the armory (found in the Bots tab).
- Livemap This map shows all known Worldforge Items, bots and players on the map, you can even right click the map and directly teleport to the specified location.
- SideKick Implemented
- DB.Exile Impleneted, but due to its size (13gb), you have to manually download it and run it, you only have to run it once, The Dashboard will remember and do it for you next time.
- db.ascension is also implemented, but its still WIP, so not all pages work yet, its also not 100% up to date.
- Account lookup, create accounts and set GM levels.
- Add Item Menu, This menu lets you quickly add items to yourself or other players, it reads your database for items, it also includes favorites for faster access and a kit system to easily spawn kits (1 kit could be 4 bags, exp potions, an aura and some heirlooms).
- Lookup and control Bans and Mutes.
- Ticket System, you can read tickets made ingame.
- Realmlist Control
- Built in LUA Editor for your configs.
- Easy access to change your config paramenters rather than looking up the files manually.
